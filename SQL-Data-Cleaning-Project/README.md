# Nashville Housing Data Cleaning using SQL

## Project Overview

This project focuses on cleaning and transforming raw Nashville housing data using SQL. The objective was to improve data quality and prepare the dataset for reporting and analysis by handling inconsistencies, duplicates, and formatting issues.

## Objectives

* Clean and standardize raw housing data.
* Improve data quality for analysis.
* Remove duplicate records.
* Handle missing and inconsistent values.
* Create a structured dataset suitable for reporting.

## Tools & Technologies

* SQL
* SQL Server Management Studio (SSMS)

## Data Cleaning Tasks Performed

* Standardized date formats.
* Handled null and missing values.
* Removed duplicate records using Window Functions.
* Split address columns into separate fields.
* Standardized categorical values for consistency.
* Removed unnecessary columns after transformation.

## SQL Concepts Used

* Common Table Expressions (CTEs)
* Window Functions
* ROW_NUMBER()
* Joins
* String Functions
* Data Type Conversions
* Conditional Logic

## Key Outcomes

* Improved overall data quality and consistency.
* Reduced duplicate and redundant records.
* Created a cleaner dataset suitable for analysis and reporting.
* Demonstrated practical SQL data cleaning techniques commonly used in real-world projects.

## Business Value

Clean and accurate data is essential for effective reporting and decision-making. This project demonstrates how SQL can be used to transform raw datasets into reliable analytical assets.
